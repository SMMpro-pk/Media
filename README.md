# SMMpro Media

Public media library for [SMMpro](https://smmpro.pk) social posts. Files here are fetched by SMMpro (via raw URL) and attached to posts.

## Structure

```
images/   # graphics and photos (PNG, JPG, WebP, GIF)
videos/   # videos (MP4, WebM, MOV)
```

## Rules

- Max file size: **25 MB** (SMMpro upload limit). GitHub hard limit is 100 MB.
- Use lowercase, hyphenated, descriptive names, e.g. `instagram-affiliate-links-2026-11-17.png`.
- Never overwrite a published file. Add a new filename for each new version.
- Everything here is **public**. Do not commit private or embargoed material.

## Raw URL format

```
https://raw.githubusercontent.com/SMMpro-pk/Media/main/images/<file>
https://raw.githubusercontent.com/SMMpro-pk/Media/main/videos/<file>
```
