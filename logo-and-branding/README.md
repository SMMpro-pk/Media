# SMMpro Logo & Branding

Official SMMpro logo files.

## Logos (`logos/`)

| File | Layout | Use on |
|------|--------|--------|
| `smmpro-logo-stacked-for-light-bg.png` | Stacked (icon above wordmark), 2000x2000 | Light / white backgrounds |
| `smmpro-logo-stacked-for-dark-bg.png` | Stacked, white "SMM" + purple "pro" | Dark backgrounds |
| `smmpro-logo-horizontal-for-light-bg.png` | Horizontal (icon + wordmark), 1536x593 | Light / white backgrounds |
| `smmpro-logo-horizontal-for-dark-bg.png` | Horizontal, white "SMM" + purple "pro" | Dark backgrounds |

The white parts of the dark-background versions are only visible on a dark backdrop.
